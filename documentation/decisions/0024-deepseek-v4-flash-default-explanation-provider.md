# ADR 0024: DeepSeek V4 Flash as Default Explanation Provider

## Decision

Use DeepSeek V4 Flash as the default hosted explanation provider.

The default runtime configuration should prefer:

- `EXPLANATION_PROVIDER=deepseek`
- `DEEPSEEK_MODEL=deepseek-v4-flash`

Gemini remains supported as an alternative hosted provider. The rules-based provider remains the fallback path.

## Context

MacroLens explanations sit downstream of stored anomaly, correlation, cluster, and news-context evidence. The model provider is therefore an interpreter of persisted evidence, not the source of truth.

The previous default was rules-based, with OpenAI and Gemini available as hosted paths. That was safe but limited the default explanation quality. The project now needs a hosted default while preserving deterministic fallback behavior.

DeepSeek V4 Flash is available through DeepSeek's OpenAI-compatible Chat Completions API and is the preferred default for a low-latency hosted explanation path.

## Alternatives Considered

- Keep `rules_based` as the default.
- Make Gemini the default hosted provider.
- Make OpenAI the default hosted provider.
- Add DeepSeek only as an optional provider without changing the default.

## Reasoning

Keeping `rules_based` as the default is operationally safe, but it underuses the provider abstraction and leaves the product in a transitional state.

Making Gemini the default would conflict with the new provider preference. Gemini should remain available for comparison and fallback experiments, but it should not be the primary hosted path.

Making OpenAI the default is technically straightforward, but the requested operating direction is DeepSeek-first.

Adding DeepSeek without making it default would leave configuration and agent behavior ambiguous. The default should be explicit in code, `.env.example`, and `AGENTS.md`.

## Consequences

- New local environments default to `deepseek`.
- Runs without `DEEPSEEK_API_KEY` fall back to `rules_based` when fallback remains enabled.
- Stored explanations generated by the new default use provider `deepseek` and model `deepseek-v4-flash`.
- Provider evaluation should now compare DeepSeek, Gemini, OpenAI, and rules-based fallback output.
- Hosted output still requires grounding checks because fluent model text can overstate weak evidence.
